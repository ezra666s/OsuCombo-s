# Osu Combo — счётчик комбо для PvP (Fabric, Minecraft 1.21.11)

Клиентский мод: ставить на сервер не нужно.

## Что делает

- **Каждый удар по игроку** (обычный или критический) прибавляет +1 к комбо.
- Комбо **сбрасывается**, если ты **промахнулся** (клик атаки без удара по сущности) или **4 секунды** не наносил ударов. Получение урона комбо не сбрасывает.
- Сверху по центру экрана стоит большой счётчик `12x`. На каждый удар он «пульсирует»: на мгновение увеличивается и возвращается к обычному размеру, как в osu!. После крита вспыхивает красным. Когда комбо обрывается, красный счётчик проваливается вниз и исчезает.
- При каждом ударе из нижней части экрана **вылетает цифра** с номером комбо (1, 2, 3 …), по очереди то вправо, то влево, и уменьшается до нуля. Цифры критов красные и крупнее.

Критом считается удар по условиям ванили: падаешь, не на земле, не в воде и не на лестнице, нет слепоты, не едешь верхом, **не бежишь** и шкала атаки заряжена больше чем на 90%.

## Сборка

Нужны Java 21 и интернет (Gradle скачает всё сам).

```
./gradlew build          # Windows: gradlew.bat build
```

Готовый мод: `build/libs/osucombo-1.0.0.jar`. Положи его в `.minecraft/mods/` вместе с Fabric API для 1.21.11.

Версии Fabric лежат в `gradle.properties`. Если какая-то версия устарела, актуальные значения есть на https://fabricmc.net/develop.

## Настройки

Файл `config/osucombo.json` создаётся при первом запуске.

| Поле | По умолчанию | Что делает |
|---|---|---|
| `enabled` | `true` | включить мод |
| `resetSeconds` | `4.0` | через сколько секунд без ударов комбо сбрасывается |
| `playersOnly` | `true` | считать только удары по игрокам. Для теста поставь `false` и бей мобов |
| `showCounter` | `true` | большой счётчик сверху по центру |
| `showFlyingNumbers` | `true` | вылетающие цифры |
| `pulse` | `true` | анимация «пульса» счётчика |
| `minCombo` | `1` | с какого комбо показывать большой счётчик |
| `counterHeight` | `34` | высота счётчика |
| `counterTop` | `6` | отступ счётчика от верха экрана |
| `popupHeight` | `26` | высота вылетающих цифр |
| `popupOriginY` | `0.6` | откуда вылетают цифры по высоте экрана (0 — верх, 1 — низ) |

Размеры указаны в пикселях интерфейса (зависят от масштаба GUI в настройках видео).

## Как поменять цифры

Цифры лежат в `src/main/resources/assets/osucombo/textures/gui/combo/`:

- `n0.png` … `n9.png`, `nx.png` — обычные;
- `c0.png` … `c9.png`, `cx.png` — для критов и обрыва комбо.

Каждый файл — **96×168 пикселей** с прозрачным фоном, цифра по центру. Можно заменить файлы в проекте и пересобрать мод, либо положить такие же файлы с теми же путями в ресурспак (`assets/osucombo/textures/gui/combo/`). Файлы `.png.mcmeta` включают сглаживание, их менять не нужно.

Если у твоих цифр другая ширина, поправь `ADVANCE` (шаг между цифрами) в `ComboHud.java`.

## Известные ограничения

- Мод считает удар на клиенте. Сервер может не нанести урон (например, из-за неуязвимости цели после предыдущего удара), а мод всё равно засчитает удар. Критический удар он тоже определяет сам по ванильным условиям.
- Клик по блоку или по воздуху считается промахом.
- Буква `x` рисуется заглавной (`X`), потому что в такой форме она вровень с цифрами.
